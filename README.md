## Messenger

---

Веб-приложение — интерактивный чат для обмена сообщениями в реальном времени, аналог Telegram.

---

Учебный проект курса «Мидл фронтенд-разработчик» от Яндекс Практикума.

🔗 Демо: [Приложение](https://dragovx-messanger.netlify.app/)
🎨 Макет в Figma: [Макет](https://www.figma.com/design/jF5fFFzgGOxQeB4CmKWTiE/Chat_external_link?node-id=0-1&p=f&t=gpfwhNJlxBfmaBxc-0)

---

### Функциональность

- Регистрация и авторизация пользователей
- Список чатов с поиском
- Обмен сообщениями в реальном времени
- Настройки профиля (аватар, данные пользователя, смена пароля)
- Создание и удаление чатов
- Добавление / удаление пользователей в чате

---

### Стек технологий

- TypeScript — типизация и надёжность кода
- Vite — сборка и dev-сервер
- Handlebars — шаблонизация компонентов
- SCSS — препроцессор стилей

---

### Страницы проекта

| Путь                 | Страница                  |
| -------------------- | ------------------------- |
| `/`                  | вход                      |
| `/#register`         | регистрация               |
| `/#messenger`        | список чатов и переписка  |
| `/#profile`          | профиль                   |
| `/#profile/edit`     | изменение данных аккаунта |
| `/#profile/password` | изменение пароля аккаунта |
| `/#error500`         | ошибка сервера            |
| Ссылки не существует | 404                       |

---

### Установка и запуск

> Нужен Node.js 22 и выше

```js
npm install — Установка зависимостей
npm run dev — Запуск dev-сервера
npm run start — сборка + запуск production preview
```
